# Controls-only audit

Baseline: `447098539` on `client/controls-only` (origin `e5055515b`). Written before implementation. Entries marked **Rework required** are decisions, not claims of completed work; completion and validation will be recorded below.

## Contract and findings

All gameplay requests must reach vanilla through keys and one visible mouse step at Minecraft.tick HEAD, before pick/keybind handling. Targets calculated in the tick wait for the next input step. No server-only look, physics-direction substitution, position/velocity writes, packet reminder manipulation, or immediate game-mode actions. Vanilla owns all outbound gameplay packets.

Search covered tracked Java in src/main, src/launch, src/api and fabric, including tenorclef-shaped code and reflection. No `new Serverbound*` construction or direct `Connection.send` gameplay call was found. `LookBehavior.onSendPacket` only records rotation; it does not rewrite packets. Its PRE/POST player rotation and physics-event override are nevertheless noncompliant. `PositionSync.sync` reflectively writes `positionReminder`: remove this indirect packet scheduling override.

`MixinEntity` substitutes movement yaw; `MixinLivingEntity` substitutes jump yaw and elytra angles; `MixinPlayer` substitutes swim angles. Remove these substitutions. These can disagree with the final packet even on ordinary walking. KeyboardInput bytecode in the installed 26.3 jar normalizes its Vec2; PlayerMovementInput currently does not, and its fractional analog axes cannot be reconstructed from vanilla boolean Input packets. Use vanilla keyboard-shaped input.

`MixinClientPlayerEntity`: PRE is AFTER AbstractClientPlayer.tick in this revision. Remove flight eligibility redirects and sprint event override, retaining lifecycle notifications. Sprint must be a key; near ladders release it and use ordinary movement/sneak to stop existing sprint. `PathExecutor` forces sprint off directly; PillarController and Bastion also write sprint state. Remove all live writes.

`MixinMinecraft`: keep tick lifecycle and diagnostics, use HEAD input boundary; remove extra packet processing and GUI-screen bypass. `MixinMouseHandler`: keep client-only freecam redirection, visible player turn remains vanilla. `MixinPlayerController`: remove mutating accessors/invokers once their callers are gone; read-only mining-state access is acceptable.

`MixinNetworkManager` HEAD/RETURN hooks and `MixinConnectionLockstep` counters do not cancel/modify packets. Lockstep is local-channel-only. `MixinSpectatePackets` observes received packets after vanilla applies them (removal observes before deletion); keep. PacketLog and harness readers are read-only. `MixinFireworkRocketEntity` resolves the client-side attached entity reference for prediction, not a motion override.

Container clicks are a permitted exception only on the matching open screen with movement released and no attack/use in the tick. Open InventoryScreen for player-inventory transactions. Rendering/freecam ghosts, offline predictors, and integrated-server fixture construction are distinct from live player control and retained. Swarm chat uses vanilla typed-command/chat methods and is retained.

## Implementation status

Input mailbox added; controller wrappers and direct production game-mode callers enqueue input. Block helpers no longer reset mining delays, manipulate isDestroying, sync slots, swing, or invoke game-mode actions. Inventory clicks queue until a matching screen is open, release movement/attack/use, and use the permitted screen-click call. All production hotbar writers now enqueue number-key presses. Entity actions aim first and require the actual crosshair entity. Queued calls return PASS/false rather than pretending synchronous success; boat mounting, block placement/mining and portal construction observe vehicle/world state on subsequent ticks.

Look applies only at tick HEAD through LocalPlayer.turn, quantized to sensitivity and limited to 32 degrees/tick (8 while climbing). PRE/POST, ridden-player, per-frame and physics-event look changes are removed. Free-look settings cannot select silent rotation. Vanilla input normalization restored; fractional analog requests are mapped to digital directions. Sprint requests remain the sprint key; a sneak input cancels existing sprint when needed, including ladders and their top block. No game physics or outbound packet is suppressed to satisfy the gate.

Validation pending; this document does not assert clean live runs until results are recorded.
